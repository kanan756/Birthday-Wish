# 🎉 Aesthetic Birthday Celebration Web App

An aesthetic, responsive, interactive birthday celebration web app built with modern HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features
- 🎁 **Interactive 3D Gift Box**: Click/tap to blow off the lid with celebratory confetti.
- 🎈 **Endless Running Balloons**: Continuously floating pastel balloons with interactive click/tap popping effects.
- 🎂 **Interactive Cake & Candles**: Blow out candles via click/tap, button, or **real microphone breath detection**.
- 🎵 **Aesthetic Chime Melody**: Soft 8-bit synthesizer playing the Happy Birthday melody directly using Web Audio API (no external MP3 files needed).
- 📱 **100% Fully Responsive**: Fluid typography, CSS `clamp()`, and mobile-friendly touch targets optimized for smartphones, tablets, laptops, and ultra-wide desktops.
- 🚀 **Zero Build Step**: Native static website ready for 1-click deployment on **Vercel**, **GitHub Pages**, or **Netlify**.

## 🚀 How to Deploy on Vercel

### Option 1: Via GitHub (Recommended)
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of aesthetic birthday app"
   ```
2. Create a new repository on your GitHub account (e.g. `birthday-bestie`).
3. Link and push your code:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. Go to [Vercel](https://vercel.com) &rarr; **Add New Project** &rarr; Select your GitHub repository.
5. Keep default settings (Framework Preset: *Other*) and click **Deploy**! 🚀

### Option 2: Deploy directly with Vercel CLI
```bash
npm i -g vercel
vercel
```
